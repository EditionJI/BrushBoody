## 更新说明

当新增或更新 PRD 时：
1. 在总集中新增或更新对应行
2. `<PRD 链接>` 永远指向项目仓库中的最新 PRD 文件路径
3. 使用 Git 追踪历史变更

## 模板

```markdown
| <版本> | <标题> | <需求内容（详细摘要）> | <PRD链接> |
```

**约束**：
- 四个字段内不要包含 `|` 字符，避免破坏 Markdown 表格
- `<需求内容（详细摘要）` 使用自然语言写清"目标/范围/关键规则/边界/异常/非目标"，尽量 3–8 句
