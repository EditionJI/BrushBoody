# API 接口文档

## 基础信息

- **Base URL**: `http://163.177.65.65:8082`
- **API 前缀**: `/api/v1`
- **认证方式**: JWT Bearer Token

---

## 🔐 认证接口




### 1. 用户注册

```
POST /api/v1/auth/register
```

**请求体**:
```json
{
  "username": "testuser",
  "password": "password123",
  "email": "test@example.com"
}
```

**响应**:
```json
{
  "code": 0,
  "message": "注册成功",
  "data": {
    "user": {
      "id": 1,
      "username": "testuser",
      "email": "test@example.com",
      "is_active": true,
      "created_at": "2026-02-04T10:00:00",
      "updated_at": "2026-02-04T10:00:00"
    },
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "token_type": "bearer",
    "expires_in": 7200
  }
}
```

## 🎬 视频任务接口

> **注意**: 以下接口需要认证

### 8. 创建视频任务

```
POST /api/v1/video/tasks
```

**请求体**:
```json
{
  "child_name": "小明",
  "gender": "male",
  "age": 5,
  "theme": "勇敢",
  "img_url": "https://oss.example.com/images/photo.jpg"
}
```

**响应**:
```json
{
  "task_id": "task_1234567890",
  "status": "pending",
  "message": "任务已创建，正在生成剧情"
}
```

---

### 9. 生成封面

```
POST /api/v1/video/tasks/{task_id}/cover
```

**请求体**:
```json
{
  "regenerate": false  // true=重新生成，false=使用已有封面
}
```

**响应**:
```json
{
  "task_id": "task_1234567890",
  "status": "cover_generating",
  "message": "正在生成封面"
}
```

---

### 10. 确认封面

```
POST /api/v1/video/tasks/{task_id}/confirm
```

**请求体**:
```json
{
  "confirm": true,        // true=确认，false=取消任务
  "is_shared": true       // 是否公开分享（默认 true）
}
```

**响应**:
```json
{
  "task_id": "task_1234567890",
  "status": "awaiting_confirmation",
  "message": "封面已确认，正在生成视频",
  
  "estimated_seconds": 300
}
```

---

### 11. 查询任务状态

```
GET /api/v1/video/tasks/{task_id}
```

**响应**:
```json
{
  "task_id": "task_1234567890",
  "status": "completed",
  "progress": 100,
  "video_url": "https://oss.example.com/videos/output.mp4",
  "cover_image_url": "https://oss.example.com/covers/cover.jpg",
  "story_content": {...},
  "error_message": null,
  "created_at": "2026-02-04T10:00:00",
  "updated_at": "2026-02-04T11:00:00",
  "confirmed_at": "2026-02-04T10:30:00",
  "cover_generation_count": 1
}
```

**任务状态枚举**:
- `pending` - 待处理
- `story_generating` - 剧情生成中
- `story_generated` - 剧情已生成
- `cover_generating` - 封面生成中
- `cover_ready` - 封面就绪
- `awaiting_confirmation` - 等待确认
- `video_generating` - 视频生成中
- `completed` - 已完成
- `failed` - 失败
- `cancelled` - 已取消

## 📰 信息流接口

### 12. 获取全局信息流

```
GET /api/v1/feed
```

**查询参数**:
- `limit`: 每页数量（默认 20，最大 100）
- `offset`: 偏移量（默认 0）

**无需认证**

**响应**:
```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "task_id": "task_1234567890",
      "child_name": "小明",
      "theme": "勇敢",
      "cover_image_url": "https://oss.example.com/covers/cover.jpg",
      "video_url": "https://oss.example.com/videos/output.mp4",
      "username": "testuser",
      "shared_at": "2026-02-04T10:30:00",
      "created_at": "2026-02-04T10:00:00"
    }
  ]
}
```

**说明**: 返回所有用户已分享的公开视频，按分享时间倒序

---

```
GET /api/v1/feed/mine
```

**查询参数**:
- `limit`: 每页数量（默认 20，最大 100）
- `offset`: 偏移量（默认 0）

**需要认证**

**响应**:
```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "task_id": "task_1234567890",
      "child_name": "小明",
      "theme": "勇敢",
      "cover_image_url": "https://oss.example.com/covers/cover.jpg",
      "video_url": "https://oss.example.com/videos/output.mp4",
      "shared_at": "2026-02-04T10:30:00",
      "created_at": "2026-02-04T10:00:00",
      "is_shared": true
    }
  ]
}
```

**说明**: 返回当前用户所有已完成的视频（不管是否公开）

---

### 14. 获取全局混合信息流（首页）

```
GET /api/v1/feed/global
```

**查询参数**:
- `limit`: 每页数量（默认 20，最大 100）
- `offset`: 偏移量（默认 0）

**需要认证**

**响应**:
```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "task_id": "task_1234567890",
      "child_name": "小明",
      "theme": "勇敢",
      "cover_image_url": "https://oss.example.com/covers/cover.jpg",
      "video_url": "https://oss.example.com/videos/output.mp4",
      "shared_at": "2026-02-04T10:30:00",
      "created_at": "2026-02-04T10:00:00",
      "is_shared": true,
      "is_own": false,
      "username": "testuser"
    }
  ]
}
```

**说明**:
- 返回当前用户所有已完成的视频（不管是否公开）+ 其他用户公开的视频
- `is_own`: true 表示自己的视频，false 表示别人的视频
- `is_shared`: 是否公开（自己的视频可能为 false，别人的视频始终为 true）

## 📦 其他接口

### 16. 上传图片

```
POST /api/v1/upload
```

**Content-Type**: `multipart/form-data`

**请求体**:
```
file: <图片文件>
```

**响应**:
```json
{
  "url": "https://oss.example.com/images/abc123.jpg",
  "object_key": "images/2026/02/04/abc123.jpg",
  "filename": "photo.jpg"
}
```

**支持格式**: jpg, png, gif, webp
**文件大小限制**: 10MB

## 📋 统一响应格式

所有接口返回统一格式：

```json
{
  "code": 0,           // 0=成功，非0=失败
  "message": "success",
  "data": {...}        // 具体数据，可能为 null
}
```

## 🔒 认证说明

需要认证的接口请在请求头中携带：

```
Authorization: Bearer <your_access_token>
```

Token 有效期：**2 小时**

---

## ⚠️ 错误码

| HTTP 状态码 | 说明 |
|------------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未认证/Token 无效 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 409 | 状态冲突 |
| 429 | 请求过于频繁 |
| 500 | 服务器错误 |
