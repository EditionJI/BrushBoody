## 🎨 CSS 参考说明

### 如何使用 绘本广场.css

1. **定位信息**: CSS 中的 `left/top/width/height` 可直接使用
2. **颜色值**: `#FFFFFF`, `#F5F5F5` 等可直接使用
3. **字体**: `font-family: 'PingFang SC'` 使用系统字体

## ⚠️ 实现注意事项

### 必须使用图片的元素

```
❌ 不要用 CSS 绘制:
   - 底部导航栏 → 用 底部栏.png
   - 创建按钮 → 用 Group 1321316051.png
   - 分享按钮 → 用 btn1.png

✅ 可以用 CSS 绘制:
   - 状态栏图标
   - 顶部导航
   - 卡片背景
   - 文字样式
```

### 动态内容

| 元素 | 数据来源 | 格式 |
|------|---------|------|
| 顶部标题 | userStore.lastChildInfo.name | "{name}'s Stories" |
| 卡片封面 | API返回 | cover_image_url |
| 故事名 | API返回 | child_name |
| 卡片数量 | API返回 | 动态渲染 |

### 交互行为

| 交互 | 效果 |
|------|------|
| 点击卡片 | 跳转刷牙播放器 (带taskId) |
| 点击分享按钮 | 调起系统分享 |
| 长按卡片 | 进入编辑模式 (卡片抖动 + 显示删除按钮) |
| 点击Done | 退出编辑模式 |
